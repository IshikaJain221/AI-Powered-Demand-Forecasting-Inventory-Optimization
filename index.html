how it works

Forecasting
Three models train per SKU. Whichever backtests lowest error is used automatically — a stable SKU and a volatile one don't get the same treatment.
Shock memory
Unusual demand events — a promo landing on payday, a competitor stockout — are stored as reusable fingerprints and matched against future spikes.
Supply chain risk
Products are modeled as a multi-tier bill of materials. A disruption on a raw component — export_ban, tariff — propagates up through every assembly that depends on it.
AI copilot
Questions are answered by an agent that calls real MCP tools against the live database and, when needed, fetches a real web page — the same protocol Claude Desktop uses to connect to tools.
Simulation
Compares ordering 100 vs. 200 vs. 300 units by projected stockout risk and total cost before you commit to one.
